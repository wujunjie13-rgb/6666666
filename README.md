# Latin Typing Practice Application

A comprehensive web-based application designed to help you practice typing Latin terms while improving your memory retention. This interactive tool features multiple learning modes and difficulty levels to enhance your Latin vocabulary.

## Features

### 🎯 Four Learning Modes

1. **Typing Practice**: Type Latin terms accurately while tracking your speed (WPM), accuracy, and score
2. **Memory Match**: Match Latin terms with their meanings in a classic memory card game
3. **Flashcards**: Review terms with interactive flip cards showing term and meaning
4. **Quiz**: Test your knowledge with multiple-choice questions

### 📊 Difficulty Levels

- **Beginner**: 10 essential Latin terms
- **Intermediate**: 20 commonly used terms
- **Advanced**: 30 terms including legal and academic phrases
- **Expert**: Complete collection of 85+ Latin terms

### 💡 Memory Improvement Features

The application includes several features designed to improve memory retention:

- **Spaced Repetition**: Terms are shuffled to reinforce learning through varied exposure
- **Active Recall**: Multiple exercise types require active retrieval of information
- **Visual Learning**: Color-coded feedback and progress tracking
- **Interactive Engagement**: Four different modes keep practice sessions engaging
- **Progress Tracking**: Real-time statistics show WPM, accuracy, and score

### 📚 Latin Terms Included

The application includes 84 Latin terms across various categories:

- Common phrases (et cetera, ad hoc, vice versa)
- Legal terms (habeas corpus, prima facie, corpus delicti)
- Academic phrases (alma mater, magna cum laude, curriculum vitae)
- Philosophical terms (cogito ergo sum, tabula rasa)
- Medical/Scientific terms (in vitro, in vivo, in situ)
- And many more!

## Usage

### Getting Started

1. Open `index.html` in any modern web browser
2. Select your preferred learning mode
3. Choose a difficulty level
4. Start practicing!

### Typing Practice Mode

1. Read the displayed Latin term and its meaning
2. Type the term accurately in the input field
3. Press Enter or wait for automatic validation
4. Track your progress with real-time statistics
5. Use "Skip" if you need to move to the next term

### Memory Match Mode

1. Click cards to reveal Latin terms or their meanings
2. Find matching pairs
3. Complete all matches to finish the game
4. Challenge yourself to minimize attempts

### Flashcard Mode

1. Click the card to flip between term and meaning
2. Use navigation buttons to move between cards
3. Review at your own pace
4. Perfect for memorization sessions

### Quiz Mode

1. Read the question and select the correct answer
2. Receive immediate feedback
3. Complete all questions to see your final score
4. Restart to try again and improve

## Memory Tips

The application includes built-in memory improvement tips:

- **Practice regularly**: Consistency is key to memory retention
- **Use spaced repetition**: Review terms at increasing intervals
- **Create associations**: Link Latin terms to familiar words or concepts
- **Break down complex terms**: Divide terms into smaller, memorable parts
- **Use in context**: Create sentences using the terms
